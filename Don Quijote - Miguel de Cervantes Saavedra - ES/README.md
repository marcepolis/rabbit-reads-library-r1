# Don Quijote

Author: Miguel de Cervantes Saavedra
Book ID: don-quijote-87bc971594dcfb51

Read Don Quijote on Rabbit r1.

This Creation uses normalized EPUB text in book.js.

## Controls

- Continue Reading opens the saved bookmark only.
- Start Reading starts at page 1 when there is no bookmark.
- Start from the beginning appears after a bookmark exists.
- Wheel down/up turns pages.
- Select text, then press PTT once to add a note/highlight.
- Hold the PTT button for 3 seconds to bookmark the exact page.
- Keyboard fallback: B bookmarks.
